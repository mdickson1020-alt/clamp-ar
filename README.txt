BENCH CLAMP AR - PROTOTYPE 1

Files:
  index.html
  clamp.glb
  fid01.patt ... fid04.patt

Purpose:
  Test whether each printed fiducial can independently place the clamp at the common 180 x 70 mm datum footprint.

Measured mat data encoded:
  FID01 58.24 x 59.00 mm; gap 26.38 mm (top)
  FID02 58.30 x 58.30 mm; gap 27.94 mm (right)
  FID03 54.84 x 54.84 mm; gap 28.23 mm (bottom)
  FID04 55.77 x 55.77 mm; gap 30.38 mm (left)

GLB inspection:
  raw bounds approx 28.594 x 6.900 x 7.600 units.
  Prototype assumes converter units are centimetres, so 0.01 m per raw unit.

IMPORTANT:
  Camera access requires HTTPS (or localhost). Upload this entire folder unchanged to a static HTTPS host.

FIRST TEST:
  1. Open hosted index.html on phone and allow camera.
  2. Point at FID01 first.
  3. Check recognition and approximate clamp scale/location.
  4. Test FID02-04 separately.

This is intentionally a calibration prototype. If axes/orientation are mirrored or rotated, adjust transforms after the first physical test rather than reprinting the mat.
